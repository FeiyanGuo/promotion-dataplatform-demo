# 晋升数据中台 · 原型 v0.1

面向 HRBP 的晋升数据自助查询平台原型：把「按年下载的晋升长表」在线化为「员工×年度晋升宽表」，
按账号权限控制数据范围，自助查询、下载、留痕。

## 快速开始

```bash
npm install
npm run dev        # 开发模式，前端+API 同端口 http://localhost:7100
npm run build      # 生产构建 → dist/
npm start          # 生产模式：node server/index.js（静态站点+API 同端口）
npm run build:demo # 演示版构建 → dist-demo/（纯前端、无服务器，数据在浏览器内存，发布到 GitHub Pages 用）
```

## 架构

```
app/
├── server/                  # 后端（Express，ESM）
│   ├── app.js               # API：登录/查询/导出/权限/审计，服务端强制按部门过滤
│   ├── index.js             # 生产模式独立入口（静态+API 同端口）
│   ├── lib/wideTable.js     # 长表→宽表转换（按生效年份归集，同年多条取最早）
│   └── data/                # JSON 数据源（晋升明细、花名册、账号、审计日志）
└── src/                     # 前端（React + shadcn/ui）
    ├── pages/Login.tsx      # 登录
    ├── pages/QueryPage.tsx  # 宽表查询 + Excel 下载
    └── pages/AdminPage.tsx  # 账号权限管理 + 审计日志（仅 admin）
```

`vite.config.ts` 中通过插件把 API 以中间件挂到 dev/preview 服务器，`npm run dev` 一次起全。

## 核心设计

- **组织授权到人（两级节点 + 子树继承）**：架构图由花名册的【中心】【部门】字段自动生成，树形表格内联「授权HRBP」多选字段、变更自动保存并记审计；中心授权自动覆盖其下全部部门；管理员通过白名单获得全权，不占组织授权。支持导出授权配置（xlsx）批量编辑后回导（全量替换、先校验后写入、失败整体不落盘）。
- **服务端鉴权**：查询/导出时服务端按「账号的有效部门（中心展开 ∪ 部门直授）」强制过滤，越权绕过无效；页面统计数字一律按权限范围实时计算。
- **查询页筛选栏**：进入页面自动加载权限内全量数据；筛选栏（可折叠）支持部门多选、职级区间、逐年是否晋升、姓名/工号搜索，全部 AND 关系，前端即时过滤；全字段点表头排序（数字感知）。
- **所见即所得导出**：默认导出当前筛选结果，另设「导出全量」开关；导出在服务端重新计算并记审计（含筛选条件摘要）。
- **数据导入**：管理后台「数据导入」页上传 xlsx（前端解析、带模板下载与列校验）。追加补数按主键去重更新（晋升数据：工号+生效时间；花名册：工号）；全量替换整表覆盖。花名册必需列含【中心】+【部门】。
- **宽表规则**：按晋升生效时间的自然年归集；同年多条取最早生效一条；附带累计晋升次数、首次/最近晋升时间与职级。
- **审计**：登录、查询、导出、数据导入、权限调整全部留痕（server/data/audit.json）。

## 每年数据更新

1. 从晋升系统下载当年长表（列：工号、姓名、晋升周期、晋升前职级、晋升后职级、晋升生效时间、评审结果、评审说明）。
2. 管理后台 → 数据导入 → 晋升数据导入 → 选「追加补数」上传即可，重复上传不会产生重复记录。
3. 花名册更新：全量替换上传最新表（含【中心】【部门】两列），架构图与授权列表自动更新。

## 注意事项
